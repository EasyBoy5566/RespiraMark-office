等待裝置連線
伺服器連線 機台編號 單位 床號 財編 呼吸器 連線時長 CPU 記憶體 溫度 磁碟 操作

數值取不到時顯示 —（例如該欄位在非 Pi 環境無法取得）。展開「詳細」可看到軟體版本、 剩餘空間、開機時長、降頻旗標與趨勢圖，全部操作也在裡面。 「財編」是為每台機器登記它對應的呼吸器財產編號，只顯示在本頁，裝置必須已完成配對才能設定。 床號不在此設定——之後由財編向院內系統查詢自動帶入；在那之前看板卡片顯示機台編號。 「移除」只對離線裝置有效，用途是清出版面——裝置重新連上會自動回來， 且不會撤銷它的存取權杖（要停權請用伺服器上的 tools/make_device.py --disable）。

裝置配對申請

目前沒有待核可的配對申請

新的 Pi 在設定頁輸入本伺服器位址並按「配對」後會出現在這裡。 核可前請先確認 Pi 螢幕上顯示的 6 位確認碼與這裡一致——確認碼是用來 辨認「網頁上這筆就是我手上那台機器」的，不一致代表是別台裝置送出的申請。 核可後 token 由該台 Pi 自動領取寫入，管理員不需要也看不到 token。 申請 10 分鐘內未處理即失效，Pi 端可重新申請。 注意：本伺服器第一次核可配對後，所有裝置都改為逐台驗證，原本共用同一組 權杖的舊裝置下次重連會被拒絕，需一併配對或用 tools/make_device.py 補登記。
