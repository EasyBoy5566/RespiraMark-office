# 自訂警報音

把音檔放在本資料夾，並在 `config.json` 設定檔名；重新整理監視器頁面後生效。

`alarms` 使用 `codepage:alarm code` 當鍵，可為每一種警報指定不同聲音；`levels` 是找不到個別設定時的備援。個別警報設定的優先權高於等級備援。

```json
{
  "alarms": {
    "1:10": "paw-high.wav",
    "2:CC": "peep-low.mp3"
  },
  "levels": {
    "1": "level-1.wav",
    "2": "level-2.wav"
  }
}
```

- 可用代碼請查同層上一層的 `alarm_levels.js`，例如 `1:10` 是 Airway pressure high、`2:CC` 是 PEEP low。
- 設定值只填檔名，不填路徑；檔名可用英文字母、數字、連字號、底線與小數點。
- 技術上可使用瀏覽器支援的 WAV 或 MP3；建議使用短且音量已正規化的 PCM WAV，避免超過現有 2.5 秒／5 秒重播週期。
- 音檔遺失、格式無法解碼或未設定時，程式會自動改播原本的合成警報音。
- 瀏覽器仍要求使用者先點擊或按鍵一次才允許播放聲音；這是瀏覽器的自動播放限制。

此功能只改變中央監視畫面的提示音，不會改變呼吸器本機警報。正式使用前，請由院方確認音色、音量、優先級與辨識性。
